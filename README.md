# ABC Tech: Predictive Incident Management System

**Duration:** [13th Dec 2025 – 1st Jan 2026]

**Project Type:** Client Project / ITSM Process Automation

# Overview
- A predictive analytics solution developed for ABC Tech to optimize their IT Service Management (ITSM) operations.
- By leveraging historical incident data and machine learning, this system addresses critical inefficiencies in incident handling, specifically targeting the prediction of high-priority tickets and the automation of manual tagging processes.

# Key Features
- Priority Prediction: Implemented Random Forest and Gradient Boosting models to identify high-priority incidents (P1/P2) before they escalate.
- Volume Forecasting: Developed forecasting models to predict quarterly and annual incident volumes, aiding in better resource allocation.
- Automated Tagging: Created an auto-tagging mechanism to correctly assign ticket categories and priorities, reducing reassignment delays.
- Risk Assessment: Built predictive capabilities to identify potential failures in Request for Changes (RFC) and IT assets.

# Technologies Used
- Python
- pandas, numpy
- scikit-learn (Random Forest, Gradient Boosting)
- ITIL Framework Concepts
- Matplotlib, Seaborn
